# Agent Notify 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
Agent Notify

### 1.2 产品定位
通用 AI Agent 通知中心 — 统一监控多个 AI 编码 Agent 的状态，当 Agent 需要用户确认或任务完成时，通过系统通知 + 声音提醒用户。

### 1.3 产品价值
- **解决的问题**：用户同时使用多个 AI Agent（Claude Code、Cursor、Windsurf、Aider），通知分散，容易错过重要提醒
- **核心价值**：统一通知入口，实时提醒，不遗漏任何 Agent 事件
- **差异化优势**：多 Agent 支持、插件化架构、开源免费

### 1.4 目标用户
- **主要用户**：同时使用多个 AI 编码 Agent 的开发者
- **次要用户**：需要监控 AI Agent 状态的团队负责人
- **典型场景**：
  - 开发者使用 Claude Code 进行代码生成，同时使用 Cursor 进行代码编辑
  - 开发者让 AI Agent 执行长时间任务，需要在任务完成时收到提醒
  - 开发者需要确认 AI Agent 的权限请求

## 2. 功能需求

### 2.1 核心功能（MVP）

#### F1: 多 Agent 监控
- **描述**：支持监控多个 AI Agent 的状态
- **优先级**：P0
- **验收标准**：
  - 支持 Claude Code、Cursor、Windsurf、Aider
  - 每个 Agent 可独立启用/禁用
  - 自动检测已安装的 Agent

#### F2: 系统通知
- **描述**：通过 Windows Toast 通知提醒用户
- **优先级**：P0
- **验收标准**：
  - 支持 Windows 10/11 原生 Toast 通知
  - 通知包含标题、消息、来源标识
  - 支持自定义通知开关

#### F3: 声音提醒
- **描述**：播放提示音提醒用户
- **优先级**：P0
- **验收标准**：
  - 支持 WAV/MP3/FLAC/OGG/M4A/AAC 格式
  - 支持自定义提示音文件
  - 支持音量调节
  - 支持声音开关

#### F4: 系统托盘
- **描述**：最小化到系统托盘，后台运行
- **优先级**：P0
- **验收标准**：
  - 托盘图标显示应用状态
  - 左键点击打开设置界面
  - 右键菜单显示快捷操作
  - 脉冲动画提示新通知

#### F5: 配置管理
- **描述**：用户可自定义应用行为
- **优先级**：P0
- **验收标准**：
  - 配置文件持久化（JSON 格式）
  - 支持开机自启动
  - 支持免打扰时段
  - 支持通知历史记录

### 2.2 增强功能

#### F6: 首次运行向导
- **描述**：引导用户完成初始配置
- **优先级**：P1
- **验收标准**：
  - 自动检测已安装的 Agent
  - 引导配置 Claude Code Hook
  - 配置通知偏好
  - 配置开机自启动

#### F7: 自动更新
- **描述**：检查并下载新版本
- **优先级**：P1
- **验收标准**：
  - 后台检查 GitHub Releases
  - 显示更新提示横幅
  - 支持一键下载更新
  - 支持重试机制

#### F8: 诊断功能
- **描述**：帮助用户排查配置问题
- **优先级**：P1
- **验收标准**：
  - 检查信号目录权限
  - 检查 Claude Code Hook 配置
  - 检查 Toast 通知权限
  - 显示诊断结果

#### F9: 自适应轮询
- **描述**：根据事件频率动态调整轮询间隔
- **优先级**：P2
- **验收标准**：
  - 事件频繁时降低轮询间隔
  - 长时间无事件时增加轮询间隔
  - 夜间自动降低频率
  - 提供性能统计

### 2.3 扩展功能

#### F10: YAML 自定义 Agent
- **描述**：通过 YAML 配置添加自定义 Agent
- **优先级**：P2
- **验收标准**：
  - 支持 YAML 格式配置
  - 自动加载自定义 Agent
  - 支持自定义事件映射

#### F11: 通知历史
- **描述**：记录和显示通知历史
- **优先级**：P2
- **验收标准**：
  - 持久化存储通知记录
  - 支持按类型过滤
  - 支持清除历史

#### F12: 全局快捷键
- **描述**：通过快捷键控制应用
- **优先级**：P2
- **验收标准**：
  - Ctrl+Shift+P 暂停/恢复监控
  - 快捷键可配置

## 3. 非功能需求

### 3.1 性能要求
- 启动时间：< 3 秒
- 内存占用：< 100 MB
- CPU 占用：< 5%（正常轮询）
- 通知延迟：< 1 秒

### 3.2 兼容性要求
- 操作系统：Windows 10/11 (x64)
- Python 版本：3.10+
- 依赖：PySide6 >= 6.10, winotify >= 1.1

### 3.3 安全要求
- 不收集用户数据
- 不联网（除更新检查外）
- 配置文件本地存储
- 无管理员权限要求

### 3.4 可靠性要求
- 单实例运行（Mutex 锁）
- 崩溃自动恢复（crash.log）
- 配置文件原子写入
- 重试机制（关键操作）

## 4. 用户故事

### 4.1 核心用户故事

**US1: 开发者收到 Claude Code 通知**
> 作为开发者，我希望在 Claude Code 需要确认时收到系统通知，这样我就不会错过权限请求。

**验收标准**：
- Claude Code 发送 Notification hook 时，弹出 Toast 通知
- 通知包含消息内容
- 同时播放提示音

**US2: 开发者监控多个 Agent**
> 作为开发者，我希望在一个应用中监控所有 AI Agent 的状态，这样我就不用在多个窗口间切换。

**验收标准**：
- 设置界面显示所有已启用的 Agent
- 每个 Agent 独立显示状态
- 可单独启用/禁用每个 Agent

**US3: 开发者自定义通知偏好**
> 作为开发者，我希望自定义通知方式（声音、Toast、免打扰），这样我就能根据工作环境调整。

**验收标准**：
- 可开关声音和 Toast 通知
- 可设置免打扰时段
- 可自定义提示音文件
- 可调节音量

### 4.2 增强用户故事

**US4: 开发者首次使用**
> 作为新用户，我希望有向导引导我完成配置，这样我能快速上手。

**验收标准**：
- 首次启动显示配置向导
- 自动检测已安装的 Agent
- 引导配置 Claude Code Hook

**US5: 开发者排查问题**
> 作为用户，我希望有诊断功能帮我排查配置问题，这样我就不用手动检查每个配置项。

**验收标准**：
- 一键运行诊断检查
- 显示检查结果和建议
- 提供修复指引
