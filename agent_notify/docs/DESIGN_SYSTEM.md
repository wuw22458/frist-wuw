## 5. 动效规范

### 5.1 微交互 (< 100ms)

当前项目未使用 < 100ms 的独立微交互动画。按钮悬停/按下通过 Qt 样式表即时切换。

### 5.2 状态变化 (200-500ms)

| 动画 | 时长 | 缓动曲线 | 说明 |
|------|------|----------|------|
| ToggleSwitch 滑块 | 200ms | OutCubic | 开关切换时滑块平滑滑动 |
| 托盘脉冲 | 350ms 间隔 | 离散切换 | 收到通知时图标闪烁（蓝/白交替） |
| 脉冲持续 | 3500ms | — | 脉冲动画自动停止的超时时间 |
| 运行时长刷新 | 30000ms | — | StatusIndicator 定时器间隔 |

### 5.3 缓动曲线

| 曲线 | 用途 |
|------|------|
| QEasingCurve.OutCubic | ToggleSwitch 动画（减速进入） |

### 5.4 窗口行为

- 设置窗口关闭时隐藏到托盘（不销毁），首次关闭显示托盘提示
- 窗口几何通过 QSettings 持久化，下次打开恢复位置和大小

## 9. 设计原则

1. **暗色优先**: 整体采用 GitHub Dark 风格暗色主题，减少视觉疲劳
2. **毛玻璃美学**: 卡片使用半透明背景 + 细边框，营造层次感
3. **胶囊按钮**: 所有按钮采用大圆角胶囊造型，视觉柔和
4. **信息密度适中**: 8px 网格保证节奏感，不过度拥挤
5. **状态即时反馈**: 颜色变化即时，ToggleSwitch 200ms 平滑过渡
6. **中文字体优先**: 字体栈中 Microsoft YaHei UI 优先于 Segoe UI
